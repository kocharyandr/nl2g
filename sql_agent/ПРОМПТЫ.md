- построй график выручки по городам
- построй график динамики выручки по месяцам

- выручка по форматам магазинов — столбчатая диаграмма
- построй график выручки категории напитки по месяцам
- сколько магазинов в каждом городе — покажи диаграммой
- средняя цена товара в каждой категории — график

После построенного графика (система ждёт решения):

- а теперь линией
- подтвердить
- любая правка текстом: «сделай заголовок крупнее», «убери подписи значений»

## Чат — другие базы (выпадающий список «База данных»)

Выберите базу в списке рядом с галочкой — и вопросы к другим базам работают
прямо в чате. Вопросы «сколько …» возвращают число текстом с показом SQL:

- база `WorldSoccerDataBase`: сколько матчей прошло в Испании в 2010 году → 842
- база `GeoNuclearData`: сколько действующих энергоблоков во Франции → 58
- база `GeoNuclearData`: построй график: топ-3 страны по числу энергоблоков с количеством
- база `TheHistoryofBaseball`: сколько игроков весят больше 200 фунтов → 4584

## Базы PAUQ — русская адаптация Spider (166 баз, префикс `pauq_`)

Выберите базу в выпадающем списке, затем вопрос. Всё проверено прогоном.

**Построение графика:**

| База | Вопрос |
| --- | --- |
| `pauq_world_1` | построй график: топ-10 стран по населению |
| `pauq_world_1` | сколько стран в каждом континенте — построй диаграмму |
| `pauq_world_1` | средняя продолжительность жизни по континентам — построй график |
| `pauq_world_1` | топ-10 языков по числу стран, где на них говорят — график |
| `pauq_car_1` | построй график: сколько моделей машин с каждым числом цилиндров |
| `pauq_car_1` | средний расход топлива по годам выпуска — построй график |
| `pauq_flight_2` | топ-10 аэропортов по числу вылетов — построй график |
| `pauq_flight_2` | сколько рейсов у каждой авиакомпании — диаграмма |
| `pauq_wta_1` | распределение теннисисток по рабочей руке — построй график |
| `pauq_wta_1` | топ-10 стран по числу теннисисток — построй график |

**Правки построенного графика** (отправлять, пока система ждёт решения):

- сделай столбцы горизонтальными — работает
- поменяй цвет линии на красный и добавь маркеры — работает
- убери подписи значений и добавь горизонтальную сетку — работает
- сделай круговую диаграмму — ⚠️ теряет подписи категорий
- отсортируй по возрастанию и сделай столбцы зелёными — ⚠️ ломает график и искажает данные

**Генеративные правки** (после «Подтвердить», ~2.5 мин):

- поменяй стиль на космический
- сделай в стиле деловой презентации

⚠️ **Важно про правки.** Проверено: изменение, затрагивающее порядок или структуру
данных, может молча подменить цифры — на вопросе про аэропорты в базе 149 вылетов,
на графике до правки 39, после правки 19. Оформительские правки (цвет, сетка,
поворот подписей) безопасны; всё остальное сверяйте с таблицей под графиком.

⚠️ **Про данные PAUQ.** В базы дописаны вымышленные значения для русских литералов:
континенты Атлантида, Гиперборея и Лемурия в `world_1`, певица из «России»
в `concert_singer`. Для замера точности это неважно, но как демонстрацию
«реальных данных» такие графики показывать не стоит.
