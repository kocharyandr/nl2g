# Пул русских вопросов (проверено на живой системе)

Каждая пара «вопрос → ответ» прогнана через `sql_agent` с LoRA-моделями.
Время ответа — 15–25 с на вопрос. Вопросы к «РозничнаяСеть» можно задавать
и в чате (http://localhost:7861, галочка «Данные из базы») — тогда вместо
таблицы будет график.

## База `РозничнаяСеть` — русская схема: таблицы `магазины`, `товары`, `продажи`

