## Выводы
- Переобучения на старые промпты не видно: незнакомый вопрос (нижние N) решён верно, незнакомый стиль (акварель) отрисован адекватно.
- Два системных ограничения UI Матвея, не связанных с моделями:
  1. В состоянии ожидания подтверждения новый вопрос к базе задать нельзя — сначала «Отмена» (или новая сессия).
  2. После ошибки любое сообщение при включённой галочке трактуется как новый SQL-вопрос, даже если это правка оформления.
- С `OLLAMA_KEEP_ALIVE=0` каждый LLM-вызов перегружает модель: диффузионный шаг ~10 мин вместо ~3.

Не прогнано (остановлено пользователем): вопрос про старые/новые магазины в чистой сессии; «сколько штук каждого товара ушло в Казани за первый квартал» → «переверни… оттенки серого» → неоновая вывеска.
